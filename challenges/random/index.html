Șeriful Consolei

Un flag este ascuns în DOM-ul acestei pagini, în două bucăți. Nimic util nu este vizibil pe pagină.

Reguli:

  • Două elemente din DOM conțin, fiecare, câte o jumătate din flag, codificată în base64, într-un atribut data.
  • Selectează fiecare element, concatenează cele două valori în ordine, apoi decodifică rezultatul din base64.
  • Format: flag{...}

Indicii:

  • Elementele nu se văd pe pagină, dar tot există în DOM.
  • Poți selecta un element după id cu document.querySelector('#id').
  • Valoarea din atributul data se citește cu .dataset.
